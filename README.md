# Aditya Varma — Portfolio

A responsive, dark, immersive portfolio website for GitHub Pages. Built with HTML, CSS, vanilla JavaScript, and a procedural Three.js hero visual loaded from a CDN.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and visual system
- `script.js` — mobile navigation, scroll reveals, and interactive 3D scene

## Before publishing — personalise these details
1. In `index.html`, replace `YOUR.EMAIL@example.com` with your professional email.
2. Replace `https://www.linkedin.com/` with your personal LinkedIn profile URL.
3. Add direct links and real evidence for any projects you want recruiters to inspect. The GROUND-AID link and GitHub profile are included.
4. Add a downloadable CV only after you place your approved CV PDF in the project folder and add a link to it.
5. Confirm the award wording for GROUND-AID and update it if you have an official certificate or exact category title.

The site intentionally avoids invented grades, fabricated metrics, unverified internship claims, and skill-proficiency bars. The Team Rudra, SUNDAY AI, and engineering-lab sections are described conservatively based on currently available information.

## Publish on GitHub Pages
1. Create a GitHub repository named `adityavarma9.github.io` (or use any repository and enable Pages in Settings).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish, then open the URL shown in Pages settings.

## Notes
- The Three.js hero needs an internet connection and WebGL. If it cannot load, the rest of the site still works with a styled static background.
- Google Fonts and the Three.js CDN are external resources. For a fully offline version, download and self-host those dependencies.
- Check the page on mobile after publishing, and test the email and social links.
